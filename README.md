# Deep Thinking Collaborator

一个从个人 ChatGPT 对话里蒸馏出来的 Codex skill，用来把 AI 调成更适合深度思考、技术学习、批判反馈和行动收敛的协作者。

更不正经一点说：这是一个把 1MB 多的“我到底在想什么”压缩成 `SKILL.md` 的人格蒸馏实验。

它不是让 AI “回答更长”，而是让 AI 更稳定地做到：

- 先给明确判断，而不是泛泛铺垫；
- 解释底层机制、约束和权衡；
- 把混乱问题拆成结构；
- 给具体例子、代码例子或验证路径；
- 主动指出假设、类比和表达里的风险；
- 在回答后半段把问题收敛到下一步行动。

## 来源

这个 skill 来自一次个人对话数据分析。

我把自己和 ChatGPT 的历史聊天提取出来，只看“我说的话”居然就有约 **1.05MB**：共 **1284 个对话**，约 **60.5 万字符**。这些内容里有技术学习、系统设计、LLM/Agent、Linux/C/C++、考研与面试、职业规划、社会分析、哲学类比，以及大量“我到底该怎么思考”的元问题。

分析后发现一个稳定模式：我很擅长发散、追问本质、跨领域类比，但也容易过度分析、延迟收敛、缺少明确行动闭环。于是把这个模式反向蒸馏成了一个 skill：让 AI 既能陪我深挖，也能在必要时把我拉回“下一步做什么”。

所以它有两个层次：

- 表层：一个深度思考协作者；
- 里层：一个低配版 “junjie 思考接口”，会学我怎么问、怎么怀疑、怎么类比、怎么把自己骂回执行。

## Skill

当前 skill 位于：

```text
deep-thinking-collaborator/
├── SKILL.md
└── agents/
    └── openai.yaml
```

名称：

```text
deep-thinking-collaborator
```

适合用于这些问题：

- 技术学习：操作系统、编译器、网络、AI Agent、工程实践等；
- 系统机制：架构、数据流、状态变化、失败模式；
- 项目复盘：项目亮点、失败点、面试表达；
- 观点判断：社会分析、职业决策、类比推理；
- 计划执行：目标、里程碑、验收标准、停止条件；
- 发散收敛：把“我想理解一切”压回“我下一步该产出什么”。

## 使用方式

把 `deep-thinking-collaborator` 文件夹放到 skills 目录下

然后可以这样调用：

```text
分析一下我这个项目怎么讲给面试官。
```

或者：

```text
我学 Linux 目录树和设备一直感觉没学明白，帮我从本质上拆开。
```

## 默认回答结构

除非用户要求简短或换格式，这个 skill 倾向于使用：

```text
【结论】
【底层逻辑】
【结构拆解】
【例子/类比】
【盲点/风险】
【下一步行动】
【一句话压缩】
```

它会自动选择不同模式，例如导师模式、系统模式、面试官模式、批判模式、项目经理模式、收敛教练模式。

## 设计原则

### 不是无脑鼓励

如果用户的假设不稳、类比过度、证据不足、表达有面试风险，AI 应该直接指出。

### 不是纯抽象分析

抽象解释必须连接具体例子、代码、命令、项目场景或现实决策。

### 不是无限深挖

深挖到能支持下一步行动就该停。一个好回答应该给出最小行动和停止条件。

## 边界

这个 skill 不是完整人格备份，也不是心理测评结论。它只是从聊天数据中提取出一组高频、可执行的协作偏好：深挖机制、批判假设、结构化表达、类比设边界、最后收敛到行动。

如果说它是“人格复制”，那也只能是复制一个命令行接口：输入一个混乱问题，输出一个更像 junjie 会问、会批判、会逼自己落地的问题。
